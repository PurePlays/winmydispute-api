Privacy Policy

Last updated: April 2, 2026

1. What This Product Does

WinMyDispute provides a dispute-assistance workflow through a custom GPT and supporting API. It helps users organize facts, identify possible credit-card dispute categories, and generate user-reviewable dispute materials. It is not a law firm and does not process card payments directly; checkout is handled by Stripe.

2. Information We Process

  • Dispute details: merchant names, amounts, dates, timelines, descriptions, and other facts you provide.
  • Evidence files: screenshots, PDFs, emails, receipts, chats, statements, and other files you upload for extraction or premium packaging.
  • Email address: used for license lookup, checkout creation, and saved premium case access.
  • Payment event data: Stripe checkout session IDs, payment status, and related metadata needed to fulfill premium access.
  • Operational metadata: request IDs, audit events, limited logs, and abuse-prevention telemetry.

3. How Information Flows

  • OpenAI: if evidence extraction/OCR is used, supported files may be sent to OpenAI so the service can extract structured evidence details.
  • Stripe: checkout creation and payment confirmation are handled by Stripe. We do not store full card numbers on our servers.
  • Local case persistence: intake details, extraction output, premium output, case versions, and file metadata are stored in our SQLite-backed case system so paid users can return to saved work.
  • File storage: uploaded evidence and generated artifacts are stored on disk in our secured storage area, then exposed through signed, time-limited artifact links when needed.
  • Optional Google Sheets sync: if enabled by us for internal operations, paid license events may be appended to a Google Sheet.

4. How We Use Information

  • To provide free preview analysis and premium dispute-material generation.
  • To extract structured evidence details from uploaded files.
  • To create Stripe checkout sessions and confirm premium fulfillment.
  • To let paid users return to saved case versions and generated artifacts.
  • To operate, secure, debug, and audit the API.
  • To comply with legal obligations and enforce our terms.

5. Retention

We currently retain saved case data, associated evidence metadata, generated artifacts, and premium entitlement records until they are manually deleted by us, no longer needed for operations, or required to be retained for legal, tax, accounting, fraud-prevention, or security reasons. We do not currently offer an in-product self-service deletion tool.

Signed artifact links expire automatically, but expiration of a link does not itself delete the underlying stored file.

6. Security

We use bearer-authenticated API access, scoped GPT bearer tokens, Stripe webhook signature verification, signed artifact links, request tracing, and rate limiting to reduce exposure. No system can be guaranteed perfectly secure, so users should avoid uploading full SSNs, full card numbers, passwords, one-time codes, or unrelated sensitive data.

7. Deletion and Access Requests

To request access, correction, or deletion of personal information we control, contact support@winthisdispute.com. Because the product does not yet provide self-service deletion, requests are currently handled manually. Some records may need to be retained when required for legal, accounting, security, or fraud-prevention reasons.

8. Third Parties

  • OpenAI for supported OCR/evidence extraction workflows.
  • Stripe for checkout and payment fulfillment.
  • Hosting and infrastructure providers for API delivery and storage.
  • Google Sheets only if we enable internal license-event sync.

9. Changes

We may update this policy as the product evolves. Material changes will be reflected by updating the date above.

10. Contact

Questions about this policy can be sent to support@winthisdispute.com.
